# BI 数据洞察分析 Skill

面向 ChatBI / 智能问数场景的数据结果解读助手。将已经取得的表格、指标、排名与对比数据，整理成简洁、客观的中文业务说明。

- Skill 名称：`chatbi-data-insight`
- 来源版本：`data-insight-v1.0.0`
- 核心文件：[SKILL.md](./SKILL.md)

## 能力定位

服务业务决策者，在自然语言问数得到数据之后，帮助用户快速读懂数据。它负责解释已有结果，不负责连接数据库、生成 SQL 或独立完成数据采集。

## 四类解读模式

| 输入类型 | 解读重点 |
| --- | --- |
| 单一数值 / 汇总指标 | 当前值、单位，以及已有同比或环比 |
| 多行表格 / 排名 | Top 1–3、显著差距与头部集中度 |
| 含对比的表格 | 上升下降方向、最大变化及逆势维度 |
| 汇总与明细混合 | 先汇总，再提炼关键明细，避免逐行罗列 |

## Skill 能力设计

1. **意图对齐**：先确定用户关注的指标、时间范围、业务范围和维度。
2. **按数据结构路由**：识别结果形态，选择对应解读模式，减少泛化输出。
3. **事实优先**：重点提炼 1–3 个核心数字、显著变化、异常和结构分布。
4. **规则化异常提示**：对极值、超过 ±50% 的同比/环比波动、零值或空值、Top1 超过 50% 的集中情况给出提示。
5. **输出约束**：中文业务语言，通常 3–6 句，复杂结果不超过 8 句；保留数字精度，加粗关键数值，先总后分。
6. **推断边界**：不解释原因、不预测趋势、不引入数据外的信息；建议仅在信号明确且直接来自数据时给出。

## 使用方式

将本目录放入支持 `SKILL.md` 的工具的技能目录，按该工具的加载方式使用；也可直接将 Skill 内容作为数据解读指令。

输入建议同时包含：

- 用户原始问题；
- 数据时间范围、指标含义和单位；
- 完整结果表格及可用的对比列。

### 示例（虚构数据）

**问题：** 本月各渠道订单量及环比表现如何？

| 渠道 | 订单量（单） | 环比 |
| --- | ---: | ---: |
| 直营 | 600 | +20% |
| 电商 | 300 | +5% |
| 分销 | 100 | -60% |

**解读示例：**

> 本月订单总量为 **1,000 单**，其中直营渠道 **600 单**，占比 **60%**。直营、电商分别环比增长 **20%** 和 **5%**，分销渠道环比下降 **60%**，与其他渠道方向不同。订单主要集中在直营渠道，分销变化幅度超过 50%，可优先核查对应数据。

## 使用边界与当前限制

这是规则与提示词 Skill，不包含运行引擎、数据连接器或自动化测试结果。原始定义保留不变。实际接入时应结合业务口径验证：零值不一定表示缺失；均值、占比和汇总计算需要确认分母、权重及是否重复计入汇总行。固定异常阈值不等同于统计显著性判断。
